## 关于统计

- 统计平台返回的已通过题目；提交记录按题目去重，洛谷默认读取公开主页通过题数。
- 各平台独立计数，跨平台的镜像题可能分别计入。
- 代码目录用于归档；平台过题数由提交记录获取。
- 统计工具使用 [icpc-workbench](https://github.com/ZF3373/icpc-workbench) 的平台适配器，固定版本与修改说明见 [上游来源](https://github.com/Nanithal/Algorithm-forever/blob/automation/scripts/oj-stats/vendor/icpc-workbench/UPSTREAM.md)。
